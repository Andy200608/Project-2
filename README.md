# Project 2: Blackjack

This is an updated version of my Project 1 Blackjack game. The game itself is mostly the same, but I reorganized the code and added the new topics from Project 2, including functions, arrays, vectors, searching, and sorting.

## How to Run

Open the `Source_Code` folder and compile the program with C++11 or newer:

```text
g++ -std=c++11 Proj2_Blackjack.cpp -o blackjack
./blackjack
```

The program uses players.txt to save player information.

## Features
- Play Blackjack against the dealer
- Save data for up to 10 players
- Search for a player by name
- View leaderboards by money or wins
- Load player data when the program starts
- Save player data before the program closes
## Folders
- `Source_Code` – final program
- `Versions` – earlier versions of the program
- `Documentation` – write-up, flowchart, and checkoff sheet
- `Screenshots` – examples of the final program running
